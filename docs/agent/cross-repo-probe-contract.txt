# Probe strings this repository registers against sibling repositories.
#
# Format: <repo>\t<cited path>\t<role>\t<probe>, sorted. One line per cited string. The probe is the
# last field and is taken whole, so it may contain anything except a tab. `#` starts a comment only at
# the beginning of a line -- a probe may contain one.
#
# The citing file on our side is deliberately absent: what the owner of a string needs is the set of
# strings not to reword silently, not our file layout. Matching the format
# FSx-for-ONTAP-Adoption-Playbook publishes, so a reader written for one works for both.
#
# Verified by `make outgoing-probes`, which reads each cited repository and fails when a registered
# string is gone. Hand-maintained rather than generated: a probe is a *chosen* claim-bearing substring,
# and there is nothing to derive it from.
#
# role:
#   retraction  Expected to survive. Its absence means the claim moved or was retracted, and a claim
#               here has lost its evidence. Worth failing on.
#   reread      Quotes a minimum or maximum over a measured set, so adding a measurement rewrites the
#               string while the finding stands. Firing is "read this section again", not a
#               retraction. None registered yet -- no citation here rests on a range.
#
# TWO LIMITS, BOTH MEASURED BY THE OWNER OF THE STRINGS BELOW (their #401), AND NEITHER IS A DEFECT:
#
#   1. A probe passes when the string survives **anywhere in the file**, not where the claim is. Their
#      negative test changed one of two occurrences of a figure and the gate stayed green; only
#      changing both failed it. So a probe registered against a string that appears twice is weaker
#      than one registered against a unique string. `AP 経由の操作は**遮断されない**` below occurs
#      twice in its file and is registered anyway, because the alternative single-occurrence phrasings
#      of that claim span a line break.
#   2. A surviving string only says the sentence still exists. A claim **retracted but kept as
#      history** -- which this repository does deliberately, so a reader can see what was corrected --
#      keeps every probe against it green. **Registration is a floor, not a substitute for reading.**
#
# Line breaks matter for the same reason: a probe spanning one never matches. In the English errata the
# protocol list is split across two lines, so the registration below uses the single-line form further
# down the same file.
#
# ---------------------------------------------------------------------------------------------------

# **it would arrive here as a failing gate rather than as a notification** -- which is the point.
#
# The other five cited files are starting points and see-also pointers with no claim transcribed from
# them, so nothing is registered against them. Registering a probe there would ask their owner to
# freeze wording this repository does not depend on.
