# ブロックプロトコル関連記事の ONTAP バージョン対応表

ブロックプロトコルの実測 3 本と S3 Burst Part 2 で、どの数値がどの ONTAP バージョンの
デプロイで測定されたかを 1 か所にまとめる。**版が記録できていない測定・版が単一でない
測定があり、それぞれ元の記事側で明示されている。この文書はそれを記事横断で見るための
索引であり、元の記事の記述を上書きしない。**

## 記事ごとの対応

| 記事 | 測定 | ONTAP バージョン | 備考 |
|---|---|---|---|
| A: セッション数とキュー数 | 除数の表（3 点） | 9.18.1P5 | — |
| A: セッション数とキュー数 | キュー交渉の節 | 記録なし | 別デプロイで、測定時に読み取っておらず後から取り直せない |
| B: ANA が使えるかの確認 | 一致表の読みと書き | 9.18.1 | — |
| B: ANA が使えるかの確認 | 逐次書き込み（12 点） | 記録なし | `FileSystemTypeVersion` が `null` を返し、クラスタ API から取り直す前に環境を撤去した |
| C: 数値は何で動くか | 初期のデプロイ | 9.18.1P5 | — |
| C: 数値は何で動くか | 経路別の測定 | 9.18.1P6 | — |
| C: 数値は何で動くか | 後半の 3 デプロイ | 9.18.1 | — |
| S3 Burst Part 2 | 主要な測定環境（2026-09-01・09-02） | 9.18.1P3D1 | — |
| S3 Burst Part 2 | 第二世代 NFS 2 ホストの測定 | 9.18.1P6 | 主要な測定環境とは別バージョン |

## C 自身が候補として挙げている版差

C の記事は 1 つの ONTAP バージョンで測定されていない。9.18.1P5（初期のデプロイ）、
9.18.1P6（経路別の測定）、9.18.1（後半の 3 デプロイ）にまたがる。**この版の混在は、
記事末尾に残る未解決の候補として記事自身が挙げているものであり、他の候補（測定に
使ったクライアントの違い）と並んで「候補として挙げるだけ」としている。** どちらの
候補が原因かを切り分ける追加測定は行っていない。

## この表の限界

- **各記事の測定条件表が一次情報である。** この表は版だけを抜き出した索引で、
  ファイルシステムの世代・スループットキャパシティ・SSD 構成など他の条件は
  各記事側を参照する。
- **版が記録できていない測定を、記録できている版に合わせて書き換えない。**
  「記録なし」は測定が無効という意味ではなく、版の記録が取れなかったという事実。
