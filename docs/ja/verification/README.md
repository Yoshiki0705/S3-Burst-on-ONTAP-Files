
# 測定記録の索引

このディレクトリには、**この構成について実際に測った記録**と、**まだ測っていないものの計画**が
入っています。どちらもファイル名からは区別できないので、下の表の「段階」で見てください。

**最初に見るなら 2 つです。**

1. **[S3 Access Point で書いたものが Cache 側の NFS で読めること](flexcache-s3ap-visibility.md)** —
   この構成の中心にある主張そのもの。**p50 8 ms**（2026-08-09）
2. **[スループット / IOPS / 並列度の実測](throughput-iops-concurrency.md)** —
   数値を引用する前に読む記録。**1 台の測定をストレージの上限と読むと間違える**ことが、
   この記録の中で 2 回起きています

> **どの数値も測定条件つきでしか意味を持ちません。** 引用するときはリージョン・ONTAP の版・
> ファイルシステムの世代とスループット設定・オブジェクトサイズ・並列度・何を測ったか（クライアント側か
> サービスのメトリクスか ONTAP のカウンタか）を一緒に運んでください。理由と必須項目は
> [検証状況](../verification-status.md#性能値コスト値の扱い)にあります。
