# patterns/pipelines/ — 空であることの説明

**このディレクトリに実装はありません。意図的に 0 件です。** 数えて 0 のときに、それが
「まだ無い」のか「数え方が壊れている」のかを読者が区別できるようにしておきます。

## 空である理由

この軸は**集める側と配る側を組んだ、ワークロード単位の構成**を置く場所です。
配る側がまだ `template.yaml` の形になっていないので（[`patterns/serve/`](../serve/README.md)）、
**組み合わせをテンプレート 1 枚で表せません。** 順序としてこちらが先に埋まることはありません。

**もう 1 つ理由があります。** ワークロード単位の構成を書くには、**そのワークロードで何が要るかが
確定している**必要があります。いま確定しているのは収集側の意味論と両層の性能特性で、
**主経路（拠点側 ONTAP を Cache にする形）は未検証**です
（[検証状況](../../docs/ja/verification-status.md)）。
**未検証の前提に依拠した「ワークロード構成」を出荷しない、という判断です。**
