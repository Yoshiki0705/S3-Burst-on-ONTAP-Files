**********************************************************************
* UNEXECUTED DRAFT. A reduced workload set, for targets that bill per
* byte accessed.
*
* **Why this file exists at all: on Amazon EFS the benchmark design is
* constrained by the bill, in a way it is not on FSx for ONTAP.**
*
* EFS Elastic throughput has no hourly reservation charge and instead bills
* $0.07 per GB read or written. The full set in workloads-common.txt is
* seven run definitions at 300 seconds plus 60 seconds of warm-up. At the
* single-connection rate a client actually reaches, that moves roughly
* 210 GB per run definition -- about $15 each, or $104 for one mount
* variant. The same seven runs against FSx for ONTAP cost nothing beyond
* the hourly charge already being paid.
*
* So this file keeps three run definitions at 120 seconds plus 30 of
* warm-up: about $16 per mount variant. **The reduction is a cost
* constraint, not a measurement judgement, and any figure taken with this
* file has to say so.** Shorter runs are more exposed to warm-up effects
* and to a single slow interval.
*
* The three kept are the ones that answer different questions:
*   1 MiB sequential read   -- the bandwidth ceiling
*   1 MiB sequential write  -- the write ceiling, which differs most
*   4 KiB random read       -- where the limit stops being bandwidth
*
* The definitions themselves are copied verbatim from
* workloads-common.txt. Only the run lengths and the number of run
* definitions differ, so a figure from this file and one from that file
* are the same workload measured for a different length of time.
**********************************************************************

wd=seq-bs1024k-read100,sd=*,seekpct=.0,xfersize=1024k,rdpct=100
wd=seq-bs1024k-read0,sd=*,seekpct=.0,xfersize=1024k,rdpct=0
wd=rand-bs4k-read100,sd=*,seekpct=100,xfersize=4k,rdpct=100

* 120 seconds rather than 300, and 30 of warm-up rather than 60. threads
* matches the other file so concurrency is not another difference.
rd=default,iorate=max,warmup=30,elapsed=120,interval=1,threads=512

rd=seq-read-1024k,wd=seq-bs1024k-read100
rd=seq-write-1024k,wd=seq-bs1024k-read0
rd=rand-read-4k,wd=rand-bs4k-read100
