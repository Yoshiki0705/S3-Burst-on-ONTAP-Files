# Diagrams below the readability floor. Read by tools/check_diagram_fonts.py.
#
# This file may only shrink. An unlisted violation fails the gate, and so does a listed file
# that now meets the floor -- which is what forces a line out when a diagram is fixed. Adding a
# line is possible but never quiet: it lands in the diff beside the diagram that needed it.
#
# All of these predate the gate. Authored at fontSize 11 and 12 on canvases between 1180 and
# 1550px, so a reader's 880px column receives them at roughly 6.5 to 9px.
#
# Fixing them needs one decision that is not a layout decision: whether each figure's in-image
# notes box moves into the surrounding prose. Kept in the figure, its longest line dictates the
# canvas width, and a wider canvas raises the required font again (1488px -> 24). Moved out, what
# remains is relayout: fold labels to two lines, narrow the canvas toward 880px, stack vertically.
# That is what single-site-options and throughput-bottlenecks did, which is why they are no longer
# listed. Neither needed splitting.
#
# Why each of the six is still here:
#
#   architecture-overview, cross-cloud-connectivity -- a published article embeds these by a URL
#   that resolves against a branch, not a pinned commit, so regenerating them changes what is
#   already published. Blocked on the article bodies being updated to pinned URLs first, not on
#   layout. Procedure: .private/PENDING-image-url-pinning.md
#
#   protocol-test-matrix -- deliberately left. Nothing references it, so a fix reaches no reader.
#   Revisit if a document starts embedding it, and treat it as a redesign at that point rather
#   than a font bump: it carries no measured number, so its panels can be a table instead.
#
